## Deployment Instructions

### Docker Deployment (Recommended)

```bash
# 1. Build image
docker build -f Dockerfile.monitoring -t monitoring-daemon:latest .

# 2. Run daemon
docker run -d \
  --name endpoint-monitor \
  -e HF_TOKEN=$HF_TOKEN \
  -p 9090:9090 \
  -v $(pwd)/config:/app/config:ro \
  --restart unless-stopped \
  monitoring-daemon:latest

# 3. Verify metrics
curl http://localhost:9090/metrics

# 4. Check logs
docker logs -f endpoint-monitor

# 5. Stop daemon
docker stop endpoint-monitor
```

### Configuration

Edit `config/endpoints.yaml` to configure endpoints:

```yaml
endpoints:
  my-endpoint:
    provider: huggingface
    url: https://api-inference.huggingface.co/models/my-model
    priority: CRITICAL  # CRITICAL, HIGH, MEDIUM, LOW, MINIMAL
    wake_strategy: ALWAYS_WARM  # ALWAYS_WARM, PRIORITY_BASED, REACTIVE
    health_check_interval: 30  # seconds (optional, defaults by priority)
    wake_timeout: 90  # seconds
    auth_config:
      type: bearer
      token_env: HF_TOKEN

fallback_chains:
  my-chain:
    primary: my-endpoint
    secondary: fallback-endpoint
    tertiary: final-fallback
```

### Monitoring

**Prometheus Metrics Available** (http://localhost:9090/metrics):

- `endpoint_health_status{endpoint_id, provider}`: Current health status (0-4)
- `endpoint_response_time_ms{endpoint_id, provider}`: Response time histogram
- `endpoint_wake_time_seconds{endpoint_id, provider}`: Wake time histogram
- `endpoint_consecutive_failures{endpoint_id, provider}`: Consecutive failure count
- `endpoint_fallback_total{chain_name, fallback_level}`: Fallback counter
