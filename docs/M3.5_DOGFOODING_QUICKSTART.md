# M3.5 Dogfooding Quick Start Guide

**Goal**: Get ATADO running on itself in <30 minutes

---

## Prerequisites

- ✅ M3 (Autonomous Task Generation) complete
- ✅ M4.1 (SLO Enforcement) complete
- ✅ Python 3.9+
- ✅ Git repository access
- ⚠️ Optional: LLM provider configured (Qwen/Claude)

---

## Step 1: Establish Baseline (5 minutes)

### 1.1 Run Context Snapshot

```bash
cd /path/to/unified-intelligence-cli

# Generate baseline health score
python scripts/context_snapshot.py --days 30 --no-tests --coverage-file coverage.xml

# View results
cat logs/context_snapshot_*.md
```

**Expected Output**:
```
System Health: 64.8/100 (Grade: D)

Health Factors:
  - Coverage: 50.0/100 (unknown)
  - Complexity: 69.2/100 (fair)
  - Technical Debt: 45.0/100 (poor)
  - Test Pass Rate: 100.0/100 (excellent)
  - Metrics: 83.0/100 (good)
```

### 1.2 Save Baseline

```bash
# Copy baseline for comparison
cp logs/context_snapshot_*.md logs/dogfooding_baseline.md
cp logs/context_snapshot_*.json logs/dogfooding_baseline.json
```

## Step 4: Run First Dogfooding Cycle (10 minutes)

### 4.1 Run Single Cycle

```bash
# Run 1 cycle with 5 tasks
python scripts/self_improvement_runner.py \
  --cycles 1 \
  --max-tasks 5 \
  --analysis-days 30 \
  --use-llm

# Check results
cat logs/self_improvement_report_*.md
```

**Expected Output**:
```
SELF-IMPROVEMENT SUMMARY
======================================================================
Cycles completed: 1
Tasks generated: 10
Tasks executed: 5
Success rate: 80.0%
Health trend: improving
Current health: 65.5/100
```

### 4.2 Review Generated Tasks

```bash
# View generated tasks in JSON report
cat logs/self_improvement_report_*.json | jq '.cycles[0].tasks_generated'
```

### 4.3 Manual Review (Important!)

Before executing tasks automatically, **manually review** the generated tasks:

1. Check task instructions are clear and actionable
2. Verify no dangerous operations (rm -rf, DROP TABLE, etc.)
3. Confirm tasks align with improvement opportunities
4. Validate estimated time is reasonable

---

## Step 5: Start Continuous Dogfooding (5 minutes)

### 5.1 Run Continuous Mode

```bash
# Run continuous mode (stops on stagnation)
python scripts/self_improvement_runner.py \
  --continuous \
  --max-cycles 10 \
  --max-tasks 5 \
  --delay-seconds 300 \
  --use-llm

# This will run until:
# - 10 cycles complete, OR
# - Health score stagnates (no improvement for 3 cycles)
```

### 5.2 Monitor Progress

In a separate terminal:

```bash
# Watch SLO dashboard
python scripts/slo_dashboard.py --watch --interval 10

# Or check logs
tail -f logs/self_improvement_report_*.md
```

## Troubleshooting

### Issue: No tasks generated

**Solution**:
```bash
# Check if LLM is configured
python -c "import os; print(os.getenv('QWEN_API_KEY'))"

# Try without LLM (heuristic mode)
python scripts/self_improvement_runner.py --cycles 1 --no-llm
```

### Issue: Tasks fail validation

**Solution**:
```bash
# Check validation logs
grep "REJECTED" logs/self_improvement_report_*.md

# Review validation rules
cat src/claude_orchestrator/use_cases/task_validator.py
```

### Issue: SLO violations

**Solution**:
```bash
# Check SLO dashboard
python scripts/slo_dashboard.py

# Review violations
cat logs/slo_report.md | grep "VIOLATED"

# Check auto-rollback status
grep "ROLLBACK" logs/*.log
```

### Issue: Low health score improvement

**Solution**:
```bash
# Focus on high-impact tasks
# Edit task prioritizer weights:
# - Increase impact weight to 60%
# - Decrease effort weight to 20%

# Run more cycles
python scripts/self_improvement_runner.py --cycles 10 --max-tasks 5
```
