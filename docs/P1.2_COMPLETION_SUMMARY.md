## What Was Built

A production-ready endpoint monitoring and auto-wake service for HuggingFace Inference API that:
- Monitors endpoint health with configurable intervals
- Automatically wakes sleeping endpoints based on priority
- Executes fallback chains for resilience
- Exports Prometheus metrics for observability
- Runs as containerized daemon service

## Architecture Highlights

**Clean Architecture Implementation**:
```
Entities (Domain) → Interfaces → Use Cases → Adapters → Daemon
```

**SOLID Principles**:
- **LSP**: BaseHealthChecker enforces invariants (timeout, exception handling)
- **ISP**: IWaker/IReadinessPoller split for optional capabilities
- **DIP**: Use cases depend on abstractions, not implementations
- **SRP**: Each class has single, well-defined responsibility
- **OCP**: Can add providers without modifying use cases

## How to Use

### Run Tests
```bash
. venv/bin/activate
pytest tests/monitoring/ -v
# 113 passed in 50.49s
```

### Validate Configuration
```bash
python -c "
from src.monitoring.config.loader import ConfigLoader
config = ConfigLoader.load_from_file('config/endpoints.yaml')
print(f'Endpoints: {len(config.endpoints)}')
print(f'Fallback chains: {len(config.fallback_chains)}')
"
```

### Build Docker Image
```bash
docker build -f Dockerfile.monitoring -t monitoring-daemon:latest .
```

### Run Daemon
```bash
docker run -d \
  --name endpoint-monitor \
  -e HF_TOKEN=$HF_TOKEN \
  -p 9090:9090 \
  -v $(pwd)/config:/app/config:ro \
  monitoring-daemon:latest
```

### Check Metrics
```bash
curl http://localhost:9090/metrics
```
