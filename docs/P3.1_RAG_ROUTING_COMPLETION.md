## Architecture

### Clean Architecture Compliance ✅

**Layers**:
- **Entity**: Task, Agent, AgentTeam (domain models)
- **Use Case**: Pattern retrieval, routing decisions
- **Adapter**: RAGTeamRouter, SurrealDBStore, EmbeddingPipeline
- **Interface**: IAgentSelector, team routing contracts

**SOLID Principles**:
- ✅ **SRP**: RAGTeamRouter focuses on routing, SurrealDBStore on persistence
- ✅ **OCP**: Extends TeamRouter without modifying it (Decorator pattern)
- ✅ **LSP**: RAGTeamRouter substitutable for TeamRouter
- ✅ **ISP**: Focused interfaces (IAgentSelector)
- ✅ **DIP**: Depends on abstractions (DomainClassifier, SurrealDBStore)

**Design Patterns**:
- **Decorator Pattern**: RAGTeamRouter wraps TeamRouter
- **Strategy Pattern**: Pluggable routing strategies (base, RAG, tracking)
- **Repository Pattern**: SurrealDBStore for data persistence
- **Pipeline Pattern**: EmbeddingPipeline for text → vector conversion

## Usage

### Basic Usage (RAG Enabled)

```bash
python3 -m src.main \
  --task "Your task description" \
  --provider granite \
  --routing team \
  --agents scaled \
  --enable-rag \
  --collect-metrics \
  --verbose
```

### Environment Variables

```bash
# SurrealDB connection
export SURREALDB_URL="ws://localhost:8000"

# Optional: Enable baseline tracking for A/B testing
export RAG_BASELINE_TRACK_DECISIONS="1"
```

### Configuration

RAG configuration in `src/adapters/llm/rag_config.py`:

```python
@dataclass
class RAGConfig:
    db_url: str = "ws://localhost:8000"
    db_namespace: str = "atado"
    db_database: str = "rag"
    db_user: str = "root"
    db_password: str = "root"
    embedding_provider: str = "sentence-transformers"
    embedding_model: str = "sentence-transformers/all-mpnet-base-v2"
    top_k: int = 3
    similarity_threshold: float = 0.5
```

## Deployment Prerequisites

### Required Dependencies

**Update**: Added to `pyproject.toml` (October 20, 2025):

```toml
[project.optional-dependencies]
rag = [
    "surrealdb>=0.3.0",
    "sentence-transformers>=2.2.0",

```

**Installation**:

```bash
# Install RAG dependencies
pip install -e ".[rag]"

# Or individual packages
pip install surrealdb>=0.3.0
pip install sentence-transformers>=2.2.0
```

### SurrealDB Server Setup

**Option 1: Docker (Recommended)**

```bash
docker run --rm -d \
  --name surrealdb \
  -p 8000:8000 \
  surrealdb/surrealdb:latest \
  start --log trace --user root --pass root memory
```

**Option 2: Native Installation**

```bash
# Install SurrealDB CLI
curl -sSf https://install.surrealdb.com | sh

# Start server
surreal start --log trace --user root --pass root memory
```

**Verification**:

```bash
# Check server health
curl http://localhost:8000/health

# Expected: {"status":"ok"}
```

### Schema Initialization

Schema is auto-initialized on first use, but can be manually deployed:

```bash
# Initialize schema
python3 scripts/deploy_rag_tables.py

# Or via SurrealQL file
surreal sql --conn http://localhost:8000 \
  --user root --pass root \
  --ns atado --db rag \
  < scripts/add_rag_tables.surql
```
