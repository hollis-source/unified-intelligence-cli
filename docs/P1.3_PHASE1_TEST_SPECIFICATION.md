## Manual Testing

### Basic Usage Test

```python
from src.observability.adapters import InMemoryTracer
from src.observability.decorators import trace_operation, set_global_tracer
from src.observability.entities import TraceStatus

# Setup
tracer = InMemoryTracer()
set_global_tracer(tracer)

# Test sync function
@trace_operation("test.sync")
def sync_function(x: int) -> int:
    return x * 2

result = sync_function(5)
assert result == 10

# Test async function
@trace_operation("test.async")
async def async_function(x: int) -> int:
    await asyncio.sleep(0.1)
    return x * 3

result = await async_function(5)
assert result == 15

# Verify traces
traces = tracer.get_all_traces()
assert len(traces) == 2
assert all(t.status == TraceStatus.SUCCESS for t in traces)
```

### Error Handling Test

```python
@trace_operation("test.error")
def failing_function():
    raise ValueError("Test error")

try:
    failing_function()
except ValueError:
    pass

traces = tracer.get_all_traces()
error_trace = traces[-1]
assert error_trace.status == TraceStatus.ERROR
assert "ValueError" in error_trace.error_message
```

## Performance Tests

### Overhead Measurement

```python
import time

# Baseline (no tracing)
start = time.time()
for _ in range(1000):
    sync_function(5)
baseline_time = time.time() - start

# With tracing
set_global_tracer(InMemoryTracer())
start = time.time()
for _ in range(1000):
    sync_function(5)
tracing_time = time.time() - start

overhead = (tracing_time - baseline_time) / baseline_time * 100
assert overhead < 5.0  # < 5% overhead target
```
