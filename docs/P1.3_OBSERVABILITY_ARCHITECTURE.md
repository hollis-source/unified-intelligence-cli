# P1.3 Production Observability - Architecture Design

**Priority**: P1.3
**Status**: 🔨 IN PROGRESS
**Date**: 2025-10-12
**Estimated Effort**: 14 hours
**Complexity**: Medium

## Executive Summary

P1.3 implements comprehensive production observability for the unified-intelligence-cli, enabling:
- **Distributed tracing** via OpenTelemetry for request flow visualization
- **Cost tracking** per project/task to monitor API spending
- **Usage analytics** for understanding system behavior
- **Error alerting** for proactive issue detection
- **Performance profiling** for bottleneck identification

## Requirements Analysis

### From priorities.yaml

```yaml
P1.3: Production Observability

- Cost tracking per project
- Usage analytics dashboard
- Error alerting and performance profiling
```

### Functional Requirements

1. **OpenTelemetry Tracing** (FR1):
   - Trace project builder workflows end-to-end
   - Trace multi-agent orchestration
   - Trace LLM API calls (Grok, Qwen, HuggingFace)
   - Export to Jaeger/Zipkin for visualization
   - Support distributed context propagation

2. **Cost Tracking** (FR2):
   - Track API costs per model (Grok, Qwen, etc.)
   - Aggregate costs by project, task, agent
   - Calculate cost per successful project
   - Export cost metrics to Prometheus
   - Generate cost reports

3. **Usage Analytics** (FR3):
   - Track project creation rate
   - Monitor task completion rate
   - Measure agent utilization
   - Track model selection distribution
   - Identify peak usage times

4. **Error Alerting** (FR4):
   - Alert on repeated failures (>3 consecutive)
   - Alert on high error rate (>10% in 5min)
   - Alert on cost spike (>$10/hour)
   - Alert on slow requests (>30s p99)
   - Integration with PagerDuty/Slack

5. **Performance Profiling** (FR5):
   - Measure request latency (p50, p95, p99)
   - Track slow spans (>5s)
   - Identify bottleneck operations
   - Profile memory/CPU usage
   - Generate performance reports

### Non-Functional Requirements

| Requirement | Target | Rationale |
|-------------|--------|-----------|
| **Low Overhead** | <5% CPU, <100MB RAM | Observability shouldn't slow production |
| **High Availability** | 99.9% uptime | Metrics must be reliable |
| **Data Retention** | 7d traces, 30d metrics | Balance storage vs. cost |
| **Query Performance** | <100ms for dashboards | Fast insights for operators |
| **Scalability** | 1000 traces/min | Support high-throughput production |

### Domain Model

#### Entity: Trace
```python
@dataclass(frozen=True)
class Trace:
    """Distributed trace representing a single request/workflow.

    Immutable entity tracking request flow through system.
    """
    trace_id: str  # Unique trace identifier (UUID)
    span_id: str  # Root span identifier
    parent_span_id: Optional[str]  # Parent span for distributed traces
    operation_name: str  # e.g., "project_builder.create_project"
    start_time: datetime
    end_time: Optional[datetime]
    duration_ms: Optional[float]
    status: TraceStatus  # SUCCESS, ERROR, TIMEOUT
    tags: Dict[str, str]  # Metadata (project_id, agent, model)
    baggage: Dict[str, str]  # Cross-service context

    def is_complete(self) -> bool:
        return self.end_time is not None

    def is_slow(self) -> bool:
        """Check if trace exceeds performance threshold."""
        if not self.duration_ms:
            return False
        return self.duration_ms > 30000  # 30s threshold
```

#### Entity: CostEntry
```python
@dataclass(frozen=True)
class CostEntry:
    """Cost tracking entry for a single LLM API call.

    Immutable record of API usage and associated costs.
    """
    id: str  # Unique cost entry ID
    project_id: Optional[str]
    task_id: Optional[str]
    agent_name: Optional[str]
    model_name: str  # e.g., "grok-1", "qwen3-next-80b"
    provider: str  # e.g., "x-ai", "huggingface"

    # Token usage
    input_tokens: int
    output_tokens: int
    total_tokens: int

    # Cost calculation
    input_cost_per_1k: float  # USD per 1000 input tokens
    output_cost_per_1k: float  # USD per 1000 output tokens
    total_cost_usd: float  # Calculated total cost

    # Metadata
    timestamp: datetime
    trace_id: Optional[str]  # Link to trace

    def calculate_cost(self) -> float:
        """Calculate total cost based on token usage."""
        input_cost = (self.input_tokens / 1000) * self.input_cost_per_1k
        output_cost = (self.output_tokens / 1000) * self.output_cost_per_1k
        return input_cost + output_cost
```

#### Entity: UsageMetric
```python
@dataclass(frozen=True)
class UsageMetric:
    """Usage metric for tracking system behavior.

    Immutable snapshot of system usage at a point in time.
    """
    metric_name: str  # e.g., "project_builder.tasks_completed"
    metric_type: MetricType  # COUNTER, GAUGE, HISTOGRAM
    value: float
    timestamp: datetime
    tags: Dict[str, str]  # Labels for aggregation

    def to_prometheus_format(self) -> str:
        """Convert to Prometheus metric format."""
        labels = ','.join(f'{k}="{v}"' for k, v in self.tags.items())
        return f'{self.metric_name}{{{labels}}} {self.value} {int(self.timestamp.timestamp() * 1000)}'
```

#### Entity: Alert
```python
@dataclass(frozen=True)
class Alert:
    """Alert triggered by observability system.

    Immutable notification of system issue.
    """
    alert_id: str
    severity: AlertSeverity  # INFO, WARNING, CRITICAL
    title: str
    description: str
    triggered_at: datetime
    resolved_at: Optional[datetime]
    source: str  # Component that triggered alert
    tags: Dict[str, str]

    # Alert conditions
    threshold_value: float
    actual_value: float
    evaluation_window: str  # e.g., "5m", "1h"

    def is_active(self) -> bool:
        return self.resolved_at is None

    def duration(self) -> Optional[timedelta]:
        if not self.resolved_at:
            return None
        return self.resolved_at - self.triggered_at
```

#### Entity: PerformanceProfile
```python
@dataclass(frozen=True)
class PerformanceProfile:
    """Performance profile for an operation.

    Immutable snapshot of performance characteristics.
    """
    operation_name: str

    # Latency percentiles (milliseconds)
    p50: float
    p95: float
    p99: float
    max: float

    # Throughput
    requests_per_second: float

    # Resource usage
    avg_cpu_percent: float
    avg_memory_mb: float

    # Time window
    window_start: datetime
    window_end: datetime
    sample_count: int

    def is_degraded(self) -> bool:
        """Check if performance is degraded."""
        return self.p99 > 30000  # 30s threshold
```

### Interfaces

#### ITracer
```python
class ITracer(ABC):
    """Interface for distributed tracing.

    Abstracts OpenTelemetry implementation details.
    """

    @abstractmethod
    def start_trace(self, operation_name: str, tags: Dict[str, str]) -> Trace:
        """Start a new trace."""
        pass

    @abstractmethod
    def finish_trace(self, trace: Trace, status: TraceStatus) -> Trace:
        """Finish an existing trace."""
        pass

    @abstractmethod
    def add_span(self, trace: Trace, span_name: str, tags: Dict[str, str]) -> Span:
        """Add a child span to trace."""
        pass

    @abstractmethod
    def export_traces(self, traces: List[Trace]) -> None:
        """Export traces to backend (Jaeger/Zipkin)."""
        pass
```

#### ICostTracker
```python
class ICostTracker(ABC):
    """Interface for cost tracking.

    Abstracts cost calculation and storage.
    """

    @abstractmethod
    def record_cost(self, entry: CostEntry) -> None:
        """Record a cost entry."""
        pass

    @abstractmethod
    def get_total_cost(self, project_id: str, start: datetime, end: datetime) -> float:
        """Get total cost for a project in time range."""
        pass

    @abstractmethod
    def get_cost_breakdown(self, project_id: str) -> Dict[str, float]:
        """Get cost breakdown by model/agent."""
        pass
```

#### IMetricsCollector
```python
class IMetricsCollector(ABC):
    """Interface for metrics collection.

    Abstracts Prometheus implementation.
    """

    @abstractmethod
    def record_counter(self, name: str, value: float, tags: Dict[str, str]) -> None:
        """Record a counter metric."""
        pass

    @abstractmethod
    def record_gauge(self, name: str, value: float, tags: Dict[str, str]) -> None:
        """Record a gauge metric."""
        pass

    @abstractmethod
    def record_histogram(self, name: str, value: float, tags: Dict[str, str]) -> None:
        """Record a histogram metric."""
        pass
```

#### IAlerter
```python
class IAlerter(ABC):
    """Interface for alerting.

    Abstracts alert destination (PagerDuty, Slack, etc.).
    """

    @abstractmethod
    async def send_alert(self, alert: Alert) -> bool:
        """Send an alert notification."""
        pass

    @abstractmethod
    async def resolve_alert(self, alert_id: str) -> bool:
        """Mark an alert as resolved."""
        pass
```

#### IProfiler
```python
class IProfiler(ABC):
    """Interface for performance profiling.

    Abstracts profiling implementation.
    """

    @abstractmethod
    def profile_operation(self, operation_name: str, duration_ms: float) -> None:
        """Record operation duration for profiling."""
        pass

    @abstractmethod
    def get_profile(self, operation_name: str, window: timedelta) -> PerformanceProfile:
        """Get performance profile for operation."""
        pass
```

### 2. Middleware Pattern

**Tracing Middleware**:
```python
class TracingMiddleware:
    """Middleware to automatically trace all requests."""

    def __init__(self, tracer: ITracer):
        self.tracer = tracer

    async def __call__(self, request, handler):
        trace = self.tracer.start_trace(
            operation_name=f"{request.method}_{request.path}",
            tags={"http.method": request.method, "http.path": request.path}
        )

        try:
            response = await handler(request)
            self.tracer.finish_trace(trace, TraceStatus.SUCCESS)
            return response
        except Exception as e:
            self.tracer.finish_trace(trace, TraceStatus.ERROR)
            raise
```

## SOLID Principles Compliance

### Single Responsibility Principle (SRP)
- **Tracer**: Only handles trace creation and export
- **CostTracker**: Only handles cost calculation and storage
- **MetricsCollector**: Only handles metric collection
- **Alerter**: Only handles alert delivery

### Open-Closed Principle (OCP)
- Can add new trace exporters (Zipkin, Tempo) without modifying ITracer
- Can add new alert destinations (PagerDuty, Email) without modifying IAlerter
- Can add new cost storage backends (PostgreSQL) without modifying ICostTracker

### Liskov Substitution Principle (LSP)
- All ITracer implementations must support start/finish/export operations
- All ICostTracker implementations must calculate costs consistently
- All IAlerter implementations must deliver alerts reliably

### Interface Segregation Principle (ISP)
- ITracer separated from IMetricsCollector (not all systems need both)
- IAlerter separated from IProfiler (independent concerns)
- ICostTracker standalone (not bundled with metrics)

### Dependency Inversion Principle (DIP)
- Use cases depend on interfaces (ITracer, ICostTracker), not implementations
- Adapters injected at runtime (dependency injection)
- Business logic independent of infrastructure choices
