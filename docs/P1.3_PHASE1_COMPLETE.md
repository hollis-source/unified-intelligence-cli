## Usage Examples

### Basic Tracing

```python
from src.observability.adapters import InMemoryTracer
from src.observability.decorators import trace_operation, set_global_tracer

# Setup
tracer = InMemoryTracer()
set_global_tracer(tracer)

# Trace function
@trace_operation("user.create")
def create_user(username: str):
    return {"id": 1, "username": username}

# Auto-traced!
user = create_user("alice")

# Inspect
traces = tracer.get_all_traces()
assert traces[0].status == TraceStatus.SUCCESS
assert traces[0].tags["arg.username"] == "alice"
```

### Error Handling

```python
@trace_operation("payment.process")
async def process_payment(amount: float):
    if amount <= 0:
        raise ValueError("Invalid amount")
    return {"status": "success"}

try:
    await process_payment(-10)
except ValueError:
    pass

# Error captured
traces = tracer.get_all_traces()
assert traces[0].status == TraceStatus.ERROR
assert "ValueError" in traces[0].error_message
```

### Complex Workflows

```python
@trace_operation("workflow.main")
def main_workflow():
    data = fetch_data()
    result = process_data(data)
    return result

@trace_operation("workflow.fetch")
def fetch_data():
    return [1, 2, 3]

@trace_operation("workflow.process")
def process_data(data):
    return sum(data)

result = main_workflow()

# All operations traced
traces = tracer.get_all_traces()
assert len(traces) == 3
```
